New in 1.1.0 - item code checks

- When you drag in a photo, every other file with the same item code (e.g. KEY-0001234A) is shown first and highlighted in orange. Files whose picture looks like a different item are marked "LOOKS DIFFERENT".
- New "Check item codes" button (Find duplicates tab): scans your whole library for item codes used on photos of different items.
- The search panel shows the item code read from the photo's file name.
